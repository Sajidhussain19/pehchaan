# scripts — Runnable scripts

One-off command-line tools. Run each from the project root, e.g. `python scripts/check_openai.py`.

- `check_openai.py` — confirms your OpenAI API key works (Module 1).
- `freeze_logic.py` — records the fingerprint of the frozen decision logic (Module 9; only after an approved change).
- `make_demo_candidates.py` — writes `data/results/demo_candidates.md/.json` from the final held-out results (Module 9).
- `demo_flow.py` — the two-contact-books doctor demo, end to end through the API (Module 9).
